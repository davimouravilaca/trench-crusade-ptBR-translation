# trench-crusade-ptBR-translation

Unnoficial translation of the Trench Crusade Books for the pt-BR (Brazilian Portuguese) language.

Tradução não-Oficial dos Livros de Trench Crusade para o idioma pt-BR (Português Brasileiro).

Esta tradução tem por objetivo preservar a máxima integridade possível ao texto original em Inglês, optando por manter os arcaísmos característicos da obra e adaptar expressões específicas, como termos religiosos e militares, apenas quando estritamente necessário (quando a tradução impossibilitaria a compreensão), com o intuito de transmitir aos leitores falante das línguas lusófonas a experiência mais fiel possível de Trench Crusade para seu idioma nativo.
