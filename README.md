# trench-crusade-ptBR-translation

Unnoficial translation of the official Trench Crusade Books for the pt-BR (Brazilian Portuguese) language. 

Tradução não-oficial dos Livros oficiais de Trench Crusade para o idioma pt-BR (Português Brasileiro). 

### Sobre a Tradução 🇧🇷
Esta tradução tem por objetivo preservar a máxima integridade possível ao texto original em Inglês, optando por manter os arcaísmos característicos da obra e adaptar expressões específicas, como termos religiosos e militares, apenas quando estritamente necessário (quando a tradução impossibilitaria a compreensão), com o intuito de transmitir aos leitores falante das línguas lusófonas em especial o idioma tupiniquim a experiência mais fiel possível de Trench Crusade para seu idioma nativo.

### Como usar esta tradução?

Atualmente a melhor forma de ler esta tradução é clonar o repositório (ou simplesmente baixar os arquivos) e utilizar algum leitor de arquivos MarkDown para abri-los. Eu estou utilizando o Obsidian e recomendo-o por motivos de compatibilidade, entretanto qualquer programa capaz de abrir arquivos .md será util. 

Sem planos para um PDF por enquanto, mas caso você tenha interesse em ajudar com essa questão sinta-se a vontade.
